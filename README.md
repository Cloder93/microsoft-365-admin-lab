# Microsoft 365 Administration Lab

## Project Overview

This project documents my hands-on practice with Microsoft 365 administration in a personal test tenant. The goal was to develop foundational IT support skills through user management, security groups, password resets, and license management concepts.

## Lab Environment

- Platform: Microsoft 365 Admin Center
- Organization: TrendyMerch test tenant
- Test user: John Smith
- Security group: IT Support Team

## Tasks Completed

### 1. User Account Management
- Created a test user named John Smith.
- Navigated the user account management interface.

### 2. Administrative Roles
- Reviewed the Helpdesk Administrator role and its permissions.

### 3. Security Group Management
- Created the IT Support Team security group.
- Added John Smith as a member.
- Assigned my administrator account as the group owner.
- Verified the group displayed one owner and one member.

### 4. Password Administration
- Successfully reset John Smith's password.
- Required a password change at the next sign-in.
- Verified Microsoft's password reset confirmation.

### 5. License Management
- Reviewed the Licenses and apps section.
- Identified an available Microsoft 365 Business Standard license.
- Learned the license assignment workflow without assigning a license.

## Skills Practiced

- Microsoft 365 Admin Center navigation
- User account administration
- Security group management
- Group ownership management
- Password resets
- Administrative role awareness
- License management concepts

## Lessons Learned

This lab helped me understand the differences between user accounts, security groups, administrative roles, and product licenses. I also practiced verifying changes and avoiding unnecessary changes to user accounts.

## Future Improvements

- Practice license assignment.
- Explore Microsoft Entra ID.
- Review administrative audit logs.
- Practice multifactor authentication.
- Document troubleshooting exercises.

## Project Scope

This is a personal learning project conducted in a test environment. It demonstrates foundational practice and is not a claim of production enterprise administration experience.
